# Lens Bot

Telegram-бот, который напоминает, когда пора менять контактные линзы.

Ты указываешь дату начала носки и срок линз. Накануне и в день замены бот присылает сообщение. После замены нажимаешь «Заменил(а)», и отсчёт начинается заново.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и краткая информация |
| `/new` | Новая пара линз: дата начала и срок |
| `/status` | Сколько дней осталось + кнопка «Заменил(а)» |
| `/time` | Время напоминаний (по умолчанию 09:00) |
| `/tz` | Часовой пояс (по умолчанию Москва, UTC+3) |

## Стек

Node.js 20.6+ (нужен флаг `--env-file`) · JavaScript (ES-модули) · [node-telegram-bot-api](https://www.npmjs.com/package/node-telegram-bot-api) v2 · nodemon для разработки

## Запуск

1. Создать бота у [@BotFather](https://t.me/BotFather) и получить токен.
2. Скопировать `.env.template` в `.env` и вписать `BOT_TOKEN`.
3. Установить зависимости и запустить:

```bash
yarn install
yarn dev
```

| Скрипт | Что делает |
|---|---|
| `yarn dev` | Запуск с автоперезапуском при изменениях (nodemon) |
| `yarn start` | Обычный запуск |

## Структура

```
src/
  index.js   точка входа: проверка токена, создание бота, запуск
  bot.js     команды, кнопки, диалог
  texts.js   все тексты бота
  dates.js   функции для работы с датами (без Telegram и базы)
  db.js      запросы к базе и шаги диалога (пока заглушки)
```
